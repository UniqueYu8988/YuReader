# YuBook 验收

构建成功不等于书籍可用。导入前由 Agent检查以下结果。

## 必须通过

- 外部原始文件没有变化，归档副本哈希一致。
- 书名、版次由书内证据确认；同名既有书复用稳定 ID。
- 正文从第一个可靠的第一章开始。
- 正文章、节编号连续；没有孤立的低级编号节点。
- 每个目录节点都有正确父节点和完整标题。
- 页面范围覆盖正文且没有缺口、重叠或逆序。
- 页面内容来自原文，没有摘要、改写或异常缩短。
- 固定水印不进入派生阅读页；所有正文词组修复都能在 transformations 报告中追溯到原始行。
- 页面文件、manifest 和来源映射全部存在。
- 书架主目录不包含书前资料、索引字母或正文提示句。
- 抽查章际边界：位于新章之前的“篇、编、单元”等分卷标题必须进入新章首个阅读页，不能落入上一章的思考题、参考文献或其他 reference 页面。
- 在 YuReader 实际扁平目录中抽查 topic 分页，标题仍能看出所属父节。
- “字节一致”只在保留原始 CRLF/LF 后声明；否则只能报告文本等价。
- 只要候选包执行过水印移除或 `text_replacements`，派生正文就不得宣称与原始归档逐字节一致。此时应分别报告“原始归档哈希一致”“来源范围无缺口”和“派生变换可追溯”。
- 最终报告中的章节数、页面数、最短/中位数/P95/最长页面、transformations 数量和包路径必须在最后一次 build 后从该候选包的 `manifest.json` 与 reports 读取；不得沿用构建前脚本统计或旧候选包数据。
- 导入前必须对派生正文复查“全书少数写法但专业上无歧义”的重复 OCR。可用英文术语、附录术语表、全书多数写法和固定学科词组交叉确认；确定项逐行修复并记录，不得把它们笼统归入“不确定 OCR”。
- `validate` 必须直接审计应用全部 replacements 后的派生正文；已知完整术语替代和自动级缺字只要仍有一个残留，就必须作为 blocker，最终报告不得另行宣称“已清零”。
- 口腔教材除运行通用 `𬌗` 术语审计外，还要根据本书内容补查相关固定词组。例如影像学中的“咬翼片、𬌗片、X线、唾液腺、颞下颌关节、髁突、介入放射学”；这些示例用于提醒 Agent 建立本书词表，不应演变成对所有书籍的全局替换规则。
- 对书内目录、英文术语、同一行正确写法或全书多数写法已经证明的词组，要同时扫描 reading 与 reference 页面。实验教程和附录中的“聂下颌韧带”等残留不能因为不进入主阅读顺序而跳过。
- `supporting` 节点默认只能生成 `reference` 页面；若进入主阅读顺序，必须用 `reading_reason` 明确说明它为什么是核心学习单元。
- 若任务边界是“只生成候选”“先审核”或明确禁止导入，即使所有验证通过也不得调用 `import`；最终报告必须如实说明正式书架是否发生变化。
- 临时探针、一次性脚本和中间扫描结果统一放入 `notes/_scratch/`，不得把失效候选路径或大量 `_*.py`、`_*.txt` 散落在书籍工程根目录并冒充最终产物。最终统计与包路径必须可从当前工程目录直接复现。

## Agent 必须解释的 warning

- 少于300字的阅读页，或超过30000字的自然小节；
- 重复标题；
- 标题疑似 OCR 截断或提示句；
- 目录与正文标题不一致；
- 表格、图片或公式导致的特殊页面；
- 保留的不确定 OCR。

warning 不自动要求用户复核。Agent 应自行比较证据并决定修复、合并、拆分或原样保留。

## 三个真实回归样本

- 儿童口腔医学：阻止正文标签、制作步骤和索引字母进入主目录。
- 口腔修复学：完整恢复“章—节—一、二、三—（一）（二）”层级，不选择性提升标题。
- 口腔颌面外科学：发现缺失父节、编号跳跃和被截断的目录标题。

新规则只有在解决真实样本问题且没有损害其他样本时才加入主 Skill。
