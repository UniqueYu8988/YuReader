# YuBook 协作说明

YuBook 是 YuReader 内部孵化的轻量制书工具。它把一份真实 Markdown 整理成忠于原书目录、适合侧边栏 AI 阅读、可追溯且能安全导入 YuReader 的书籍包。

处理书籍时先完整阅读本目录的 `SKILL.md`，再按其中路由读取相关参考文件。不要把旧 YuBuilder 的状态机、前端、任务队列、Schema registry、MinerU 协议或多 Agent 编排迁入本项目。

## 产品标准

- 目录是否忠于原书，是第一验收标准。
- 权威目录树与阅读页面必须分开建模；Markdown 标题不是权威目录。
- 默认以原书自然“节”为阅读页。8000字不是分页上限；只有自然节超过约30000字时，才检查是否应按可靠子标题继续拆分，没有可靠边界时保持完整。
- 原始输入只读；不覆盖来源文件。
- 正文从第一个可靠的第一章开始。书前资料仅归档，不进入阅读目录。
- 清洗正文不是摘要。不得删减、改写或用 AI 内容替代原文。
- 不确定 OCR 原样保留。只执行有充分证据、逐行记录的完整词组修复和固定水印移除；原始归档始终不变。
- 每个页面必须保留原始行范围；正文范围不得遗漏、重复或逆序。
- 用户不承担逐项内容复核。Agent 自行调查、修复和验收，只有输入缺失、正文不可读或来源覆盖断裂等技术问题才停止。

## 工程边界

当前只支持相对完整的 UTF-8 Markdown。不要提前接入 PDF、MinerU、前端、模型 API 或复杂恢复系统；真实样本需要时再扩展。

工具只负责复制、哈希、检查范围、物化页面和原子导入。目录语义、层级恢复、分页与 OCR 取舍由 Agent 负责。
