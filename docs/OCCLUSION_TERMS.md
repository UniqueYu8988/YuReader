# “𬌗”专业术语与 OCR 对照表

本表是 YuReader 口腔教材导入的领域词典，不是把所有“验、合、咬”替换成“𬌗”的字表。它用于先确认完整专业术语，再识别该术语的 OCR 变体。

词表依据当前本地《口腔正畸学》《口腔修复学》《口腔种植学》《口腔解剖生理学》《牙体牙髓病学》《牙周病学》等教材交叉整理。全国科学技术名词审定委员会正在按口腔基础、疾病与技术分支审定口腔医学名词，因此本表保存为独立数据文件，后续可以更新，而不把术语永久写死在导入代码里。

## 处理等级

| 等级 | 含义 | 示例 |
| --- | --- | --- |
| 自动归一化 | 完整标准术语成立，替代字不可能组成目标语境中的正常词 | `验面 → 𬌗面`、`上骑架 → 上𬌗架`、`体验支托 → 𬌗支托` |
| 自动补字 | 𬌗完全丢失，但剩余结构仍是唯一或近乎唯一的固定术语 | `错畸形 → 错𬌗畸形`、`覆覆盖 → 覆𬌗覆盖` |
| 只检测 | 很可能缺少𬌗，但存在合法省称、近义写法或普通语句的可能 | `前牙开…`、`组牙功能`、`对牙` |
| 明确保留 | 本来就是正常现代汉语或教材采用的近义术语 | `实验、试验、经验、检验、骑跨、优雅、咬合` |

## 替代字和膨胀 OCR

对任一包含𬌗且长度大于一个字的标准术语，允许生成下列完整词组候选：

| OCR 类型 | 可能输出 | 示例 | 行为 |
| --- | --- | --- | --- |
| 单字形近 | 验 | 验力、错验畸形、牙尖交错验 | 完整术语匹配后自动归一化 |
| 单字形近 | 骑 | 骑力、上骑架、骑龈 | 完整术语匹配后自动归一化 |
| 单字形近 | 矜 | 覆矜、调矜、深覆矜 | 完整术语匹配后自动归一化 |
| 单字形近 | 雅 | 平衡雅、尖牙保护雅、雅龈距离 | 完整术语匹配后自动归一化 |
| 单字形近 | 酷 | 酷面、酷接触、酷平面 | 完整术语匹配后自动归一化 |
| 拆字表示 | 牙合 | 牙合面、错牙合畸形、牙尖交错牙合 | 完整术语匹配后统一为𬌗 |
| 双字膨胀 | 体验 | 体验面、体验支托 | 完整术语匹配后统一为𬌗 |
| 特定单字 | 合 | 合轴面线角 | 仅该固定术语自动归一化 |
| 单字残片 | 合 | 合面、合架、合接触、合平面 | 只检测；可能来自𬌗，也可能来自“咬合”丢字或“复合板”等跨词边界 |
| 单字残片 | 咬 | 咬面、咬接触、咬干扰 | 只检测；可能是“咬合”丢失“合”，不强制改成𬌗 |

不会生成或执行裸字符规则，例如不存在 `验 → 𬌗`、`雅 → 𬌗` 或 `合 → 𬌗`。完整术语替换还会检查是否与保护词重叠，因此“实验架、检验面、优雅面容”也不会因为包含“验架、验面、雅面”而被误改。实验、验证、经验、试验、检验、化验、体验、体检、骑跨、骑师、优雅、文雅、高雅、儒雅、雅致、酷似、酷爱、酷暑和普通“咬合”均保持不变。

| 污染形态 | 目标词 | 当前行为 | 主要边界或反例 |
| --- | --- | --- | --- |
| 错畸形 | 错𬌗畸形 | 自动补字 | 固定疾病名称；不匹配“错误、错位” |

| 合面／合架／合接触 | 𬌗面／𬌗架／𬌗接触 | 只检测 | 也可能来自“咬合”丢字，且要排除复合面、组合架等跨词边界 |
| 咬面／咬接触 | 𬌗面／𬌗接触 | 只检测 | 更可能是“咬合”丢失“合”，语义正确时不强制改变作者用词 |
| 影响建／影响建的关键因素 | 影响𬌗的建立／影响𬌗建立的关键因素 | 自动补字 | 口解第三章固定句式，后接句号、逗号或“的关键因素”时上下文唯一 |

最后一行是确定性流程的能力边界：如果 OCR 将“𬌗面”完整吞成孤立的“面”，没有词组、英文 `occlusal` 或专业句法线索，程序无法证明这里曾有𬌗。这类内容保留给页面侧边栏 AI 理解，不制造人工复核任务。

## 使用方法

导入前可以只读扫描一本原始 Markdown：

```powershell
python tools/audit_occlusion_terms.py --source "C:\path\to\book.md"
```

报告区分：已经正确的标准术语、可确定归一化的替代词、自动补字项、只检测的缺字候选，以及必须保留的合法词。导入时只有前两类和明确标记为 `automatic` 的补字规则会修改派生候选；`detect_only` 永不自动改正文。

新增词语时应先加入标准词表和真实例句，再决定处理等级；不要直接扩大单字替换集合。
