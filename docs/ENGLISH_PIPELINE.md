# 英语资料制作约定

YuReader 的英语区服务于四种不同的学习动作：真题训练、解析复盘、方法课阅读、词汇学习，以及贯穿它们的英语周记。它们共享来源追溯规则，但不共用一种机械拆分模板。

## 资料选择

- 真题以逐年试卷和同年详细解析为正式来源；合订本、速查版和重复答案只作核对证据，不重复入库。
- 方法课只保留能形成连续课程目录的核心资料。相近讲义先比较目录和正文覆盖，再决定是否补充。
- 词汇以一套主词表为学习入口；频率表适合作为筛选标签，不再复制成多本词汇书。
- 原 PDF、MinerU 产物和正式包分层保存。正式内容必须记录源文件 SHA-256、源页区间和提取方式。

当前第一轮只发布 2024、2025 年英语一作为近年真题样本；更早年份暂留在下载目录，不因为“资料齐全”而批量入库。每年先以一套试卷+同年详细解析做小包验证，确认题号、答案键和解析映射后再扩展。

## 页面级提取路由

每份 PDF 先逐页检查文本层，不能仅凭整份文件的第一页判断：

1. 可用文本层优先原生提取，避免对英文再次 OCR。
2. 图片页使用 MinerU Pipeline OCR；当前本机 Hybrid 后端缺少完整 CUDA Toolkit，不作为发布依赖。
3. 每页保留原页定位。表格、图表、题目框或答案速查行未可靠转成文本时，保留对应图片并产生质量警告。
4. Agent 可以修复明确的版面顺序和标题层级，但不得大规模改写英文原文，也不得凭印象补写答案。

## 四类包契约

### 真题

- 一年为一个训练单元，题目与答案/解析独立寻址。
- 必须核对题号连续性、选项 A–D、排序题候选段、翻译题 46–50、写作 51–52 和选择题答案键。
- 不能只检查 Markdown 中是否出现 `1–52`：排序题的 41–45 可能只存在于答题框图片，答案速查行也可能被版面模型漏掉。
- 选择题可以进入结构化答题；翻译与写作保留原题、个人作答和侧边栏个人解析，不伪造自动评分。
- 运行时题库每题可带一个共享的 `context_md` 阅读上下文。上下文只来自试卷原文，解析仍通过答题后返回的 `source_analysis_md` 单独显示，避免侧边栏把答案解析误读为题干。

### 详细解析

- 按同年、同部分、同题号映射到真题，不并入题干正文。
- 中英双栏容易串行；发布前必须按页验证英文原文、译文、答案精解和错项剖析的阅读顺序。
- 若某页无法可靠恢复双栏顺序，原页图片优先于错误拼接文本。

### 方法课

- 以印刷目录的章、节为权威导航，页码和 OCR 自动标题只作辅助。
- 一节可作为一个阅读页；过长时仅在明确的小标题边界拆页，不按固定字符数硬切。
- 例句、错译、正译和解析必须保持成组，图片示意不得脱离上下文。

### 词汇

- 以 Unit 为一级导航；页内遵循印刷栏序，通常先左栏后右栏。
- 单词、音标、词性、释义、词根词缀和例句保持为一个词条，不把每个单词做成书架小节。
- 黑色圆点可能被 OCR 成词首的 `o`，只能在词条结构与原页证据同时明确时删除；不进行无字典证据的全局替换。

## 发布闸门

- 来源哈希和页区间齐全，正式包可以反查到原页。
- 真题题号、选项、答案键和同年解析映射通过专用校验。
- 方法课目录连续；词汇 Unit 连续且双栏顺序抽检通过。
- 不确定内容保留原文或原页证据，不要求用户人工复核。
- 候选验证通过后再原子导入，失败不污染正式书架；个人笔记与个人解析只写入本地数据或 Obsidian。

- `question-banks/english-2025-e1/`：45 道客观题，来源为 16 页试卷与 64 页分块 OCR 解析。
- `content/english-exam-2025-e1-subjective/`：翻译、应用文写作、图表作文各一份原题页及对应解析 reference 页。
- 以上包均保留原始来源哈希、页/行区间和生成收据；验证器通过后才进入正式运行目录。
