# 04 数据迁移与兼容策略

## 1. 迁移原则

这次重构涉及用户笔记、答题记录、时长、复习结果和 Obsidian 存档，必须采用“先索引、再双读、后切换、最后退休旧入口”的顺序。

禁止：

- 先删除旧目录再验证新系统；
- 批量重写笔记正文；
- 因为文件无法映射就把它当垃圾清理；
- 同一阶段同时迁移数据、重写导航和删除旧 API；
- 通过文件修改时间伪造原始学习日期；
- 覆盖 OneDrive 中的原始教材、PDF、MinerU 结果或不属于 YuReader 的笔记。

## 2. 阶段开始前的只读清单

实施前生成一份带时间戳的审计报告，至少记录：

- Git 当前提交与工作区已有修改；
- `content/` 书籍数量、小节数量和 manifest 哈希；
- `question-banks/` 题库数量和验证结果；
- `data/activity.json` schema、日期与总秒数；
- `data/notes/` 文件名、大小、哈希和当前映射状态；
- practice、subjective、english-weekly、review、logs、weekly 目录中的用户数据清单；
- Obsidian 下 YuReader 目录清单和 Markdown 哈希；
- 当前 `/api/bootstrap`、`/api/stats`、`/api/reviews` 的摘要。

报告只读生成，不把真实笔记内容提交到 Git。

## 3. 失联笔记恢复

当前已经确认存在非空笔记文件无法映射到现有小节。恢复流程：

1. 读取笔记 YAML frontmatter、历史活动、旧 manifest、导入 release 和备份包；
2. 依次尝试精确书籍 ID + 来源行区间、原始 section ID、标题与章节位置、内容哈希；
3. 生成候选映射与证据报告；
4. 高置信度映射写入 ID 别名表，不移动原文件；
5. 读取当前小节笔记时解析别名；
6. 无法可靠映射的内容进入只读“未归档内容”索引，保持可见可打开；
7. 验证笔记数量、字节数和 SHA-256 在迁移前后没有减少。

不要求用户人工逐条复核。系统宁可保留少量未归档内容，也不能猜测性合并到错误章节。

## 4. 统一活动索引回填

### 4.1 阅读历史

从现有 `activity.json` 原样迁移：

- 旧 `section_reading_seconds` 归类为 `read`；
- 旧打开记录保留日期和最后位置；
- 无法映射的小节通过别名解析；
- 无精确时间戳时保留日期级精度，不伪造开始时间。

### 4.2 客观题

从现有 attempts 与 analyses 建立引用：

- 使用真实提交时间；
- 记录题库、题目、学科、正确性和个人解析引用；
- 不复制题干和原书解析；
- 隔离题、未提交选择和测试数据不得进入正式历史。

### 4.3 主观题

从 subjective response 和 Markdown 存档建立引用：

- 题目身份来自稳定 section / prompt 元数据；
- 非空答案和反思构成用户产出；
- 不把参考解析当作用户答案；
- 原有 Obsidian 路径继续可用。

### 4.4 英语周记

现有每周 Markdown 保留为英语学科笔记。只有可以从明确日期分隔、保存事件或已有元数据确定日期的片段才回填到对应日；无法确定日期的内容保留为周级存档，不猜测拆分。

### 4.5 旧复习、日志和周报

- 旧回顾结果作为历史 `review` 活动引用；
- 旧日志保留原日期并在记录页可见；
- 旧周报保留为历史周总结；
- 迁移后新系统不再依赖旧 workflow 完成门槛；
- 旧目录先转为兼容读取，不立即删除。

## 5. 双读与切换

### 双读阶段

- 新接口优先读统一索引；
- 若某日期尚未回填，则使用旧数据适配器只读补足；
- 新写入同时更新统一索引和必要的旧兼容字段；
- 对同一活动使用稳定去重键，避免双份统计。

### 切换条件

满足以下条件后，首页、回顾和统计才能切换到新索引：

- 新旧累计阅读秒数差异有解释且在允许范围；
- 所有非空笔记均可映射或出现在未归档索引；
- 客观题提交数与现有正式 attempts 一致；
- 主观题非空回答数一致；
- 历史日志和周报数量不减少；
- 真实浏览器完成至少一次阅读、练习、主观题、回顾闭环。

## 6. Obsidian 收敛方案

### 6.1 建议的新结构

```text
YuReader/
  医学/
    <学科>/<章节>/<小节>.md
  政治/
    <学科>/<章节>/<小节>.md
    <学科>/练习解析.md
  英语/
    <资料或考试>/...
  学习记录/
    2026/
      09/
        2026-09-02.md
```

章节笔记、练习解析和主观答案继续原地保存。每日记录只包含：

- 当天统计；
- 学习位置与 Obsidian / YuReader 链接；
- 用户回顾结果；
- 必要的少量摘要。

不在每日文件中重复复制全部章节笔记。

### 6.2 旧目录

`每日复习`、`学习日志`、`周报`、`英语周记` 等旧目录在迁移阶段保持不动。新记录页可以读取它们并标注为历史来源。只有经过完整备份、数量与哈希验证并得到用户明确授权后，才考虑移动归档；本轮默认不删除。

## 7. 原子写入与回退

- 所有 JSON 和 Markdown 更新继续使用临时文件 + 原子替换；
- schema 升级前保存带时间戳的本地备份；
- 每个迁移步骤可重复执行，重复运行不得产生重复活动；
- 每阶段建立独立 Git 提交，但真实数据备份不进入 Git；
- 失败时代码可回退，升级前数据备份可恢复；
- 不使用 `git reset --hard` 或覆盖用户现有未提交修改。

## 8. 兼容结束条件

旧实现只能在以下条件同时满足后退休：

- 连续真实使用至少覆盖两个学习日；
- 次日回顾正确汇集三科不同产出；
- 新统计与源记录可逐项解释；
- Obsidian 新旧内容均可打开；
- 未归档笔记为 0，或所有剩余项都有明确保留说明；
- 旧目录完整备份并有恢复说明。

退休意味着停止新写入和移除旧入口，不等于删除旧用户文件。
