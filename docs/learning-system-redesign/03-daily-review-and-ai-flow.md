# 03 每日学习、次日回顾与侧边栏 AI

## 1. 设计目标

重构后的日常流程不应要求用户理解日志生成条件、数据目录或题库内部结构。正常一天只包含三个自然动作：

```text
打开今日 → 回顾上次学习 → 继续或选择今天的内容
```

离开页面时不要求额外执行“结束学习”或“生成日报”。

## 2. 打开今日页

### 2.1 有待回顾内容

页面首先展示：

- `回顾 9 月 1 日的学习`；
- 当日医学、政治、英语的投入时间；
- 产生了多少份笔记、错题解析或主观答案；
- 预计回顾文本量；
- 一个“开始回顾”按钮。

它应比“继续阅读”具有更高优先级，但不阻止用户跳过并直接学习。

### 2.2 没有待回顾内容

页面不显示空的昨日任务。若昨天没有学习，则寻找最近一个尚未回顾且有有效学习产出的日期；若全部已回顾，则安静显示“暂无待回顾”。

### 2.3 继续学习

只突出最近一个可恢复活动，例如：

- 继续《牙体牙髓病学》第三章第二节；
- 继续马原第一章练习第 6 题；
- 继续 2025 英语一 Text 2；
- 继续 2024 英语二作文；
- 继续本周英语笔记。

不能继续只依赖 `last_section_id`。

## 3. 学习中的共同交互

所有学习工作区需要共享一组稳定但克制的操作：

- 返回资料主页；
- 打开 / 收起个人产出区；
- 打开当前 Obsidian 文件；
- 显示保存状态；
- 结束当前活动或稍后继续。

侧边栏 Gemini 不需要网页 API。页面只需要保证：

- 当前原文、题目或材料处在可读取 DOM 中；
- 标题明确标注学科、资料、章节或题型；
- 参考答案在作答前不提前暴露；
- 个人笔记 / 答案 / 解析有清楚的粘贴位置；
- AI 结果与原书内容视觉和数据上保持分离。

## 4. 次日回顾页面

### 4.1 内容来源

页面动态读取统一学习记录所引用的原地数据，不再根据文件修改时间猜测“昨天写了什么”。

建议顺序：

```text
昨日概览

医学
  学习来源 A
    - 章节位置、时长
    - 用户章节笔记
  学习来源 B
    - 主观题答案或反思

政治
  - 章节笔记
  - 错题与个人解析

英语
  - 阅读或词汇笔记
  - 真题错题
  - 翻译 / 作文答案与反思
```

仅阅读但没有个人产出的条目显示为简短轨迹，不把整节原文复制到回顾文档。

### 4.2 分页策略

默认提供一个完整的“全部”视图，方便侧边栏一次读取。医学、政治、英语分组同时作为可选过滤器。

只有在真实数据证明浏览器或侧边栏读取出现压力时，才按完整学科边界分页；不得按固定字符数切断一份笔记或一个题目。分页属于性能降级方案，不应成为日常必须逐页完成的任务。

### 4.3 完成方式

页面只保留一个主要输入区：`本次回顾结果`。

用户可以：

1. 让 Gemini 侧边栏读取当前页面；
2. 运行固定的“昨日回顾”Skill；
3. 将最终 Markdown 粘贴到该输入区；
4. 自动保存后完成本日期回顾。

不再要求：

- 每本书单独粘贴一份复习成果；
- 全部书目完成后才能打开日报；
- 再进行第二次 Gemini 总结；
- 手动点击生成日志。

如果用户只想快速浏览而不粘贴 AI 结果，可以选择“标记已回顾”，但系统应记录这是无文本回顾，避免伪造总结内容。

## 5. 建议的 Gemini 回顾 Skill 契约

本阶段只定义输出契约，不在 YuReader 中调用模型。

侧边栏 Skill 应根据页面已有内容完成：

1. 用少量主动回忆问题检查关键内容；
2. 对错题、模糊点和主观答案给予针对性反馈；
3. 识别跨书或跨学科的重复概念，但不强行建立宏大知识图谱；
4. 最后输出一份可直接粘贴的 Markdown 回顾结果。

推荐输出结构：

```markdown
## 昨日学习概览

- 学习范围：……
- 核心收获：……

## 回忆检查

1. ……
2. ……

## 易错与薄弱点

- ……

## 今天需要带着的问题

- ……
```

Skill 不应大篇幅复述所有原笔记，也不应把推测写成原书事实。用户粘贴的内容属于个人回顾结果，不回写原章节正文。

## 6. 每日记录

每天一旦产生有效学习活动，记录视图就自动存在，至少包含：

- 学习日期；
- 总有效时长；
- 医学、政治、英语分布；
- 阅读、练习、主观作答、笔记、回顾分布；
- 学习过的资料和稳定位置；
- 用户产出链接；
- 若已完成回顾，则显示回顾结果。

日报不是一份必须手动创建的第二份笔记。网页可以动态展示完整索引；Obsidian 镜像保存简洁索引、用户回顾结果和原地笔记链接。

## 7. 周视图

周视图自动汇总七天的每日记录，展示：

- 总时长及三科分布；
- 每天的学习主题；
- 已完成 / 未完成回顾；
- 每日回顾结果的简短列表。

用户需要阶段总结时，可以让 Gemini 读取周视图并粘贴一份周总结。没有周总结文本时，周视图仍然完整存在。

## 8. 不同学习形态如何进入同一流程

### 医学教材

阅读小节 → 章节笔记 → 计时与位置进入当日记录 → 笔记进入下一次回顾。

### 政治讲义与选择题

阅读小节 → 进入关联练习 → 保存答案和个人解析 → 错题与解析进入下一次回顾。

### 英语方法课与词汇

阅读学习单元 → 保存笔记或当日片段 → 进入下一次回顾。

### 英语真题客观题

按题型工作区作答 → 记录题组位置和错误 → 错题、个人解析进入下一次回顾。

### 翻译、作文与未来医学主观题

查看原题 → 独立作答 → 侧边栏批改 → 将精品结果粘回个人答案 / 反思区 → 一并进入下一次回顾。

## 9. 失败与中断

- 保存失败时保留输入并明确提示，不静默丢失；
- 回顾生成失败不影响原始笔记和当日记录；
- 用户中途关闭页面时，继续位置仍可恢复；
- 某个来源文件暂时找不到时，回顾显示“来源暂不可用”，其他内容仍可使用；
- Obsidian 不可用时继续保存到本地，恢复连接后再显式同步，不阻断学习。
