# YuReader

YuReader 是用户本人使用的本地个人学习平台，以阅读为核心：

```text
阅读 / 练习 / 笔记 → 统一学习记录 → 继续学习 / 回顾 / 记录
                   → Obsidian 镜像（可选）
```

它从 YuQuiz 0.1.1 的真实界面体系分支出来，保留已经验证过的字体、暖色纸张、细线分隔、章节阅读工具条、侧边栏折叠、深浅色主题、克制动效和笔记浮窗。政治讲义、英语方法/词汇/基础阅读资料与 2010–2025 英语一/英语二真题包已经作为本地运行时资料发布；最小答题与个人解析闭环已实现，模拟考试仍未实现。

## 学习领域

全局主导航收敛为 今日 / 学习库 / 回顾 / 记录；学习库内部提供 医学 / 政治 / 英语 三个学科入口，并按各自真实资料组织三段学习路径。统计仍是记录下的次级视图；面向用户的主路径收敛为 学科 → 资料或训练 → 单个学习单元。版本和来源系列只作为元数据，不增加一层导航。既有医学书籍没有新字段时，运行时安全回退为 `domain=medicine`、`resource_type=book`、`subject=书名`，不为此批量改写正式书架包。正式目录中的练习入口遵循规则：只有存在真实题目关联（稳定知识位置）时才显示，没有真实题库样本时保留明确空状态，不制造假入口。

## 当前能力

- 读取 `content/` 下的普通 Markdown，也可读取带稳定 ID、来源映射和质量状态的发布包。
- 学习库顶部统一切换医学 / 政治 / 英语，取消搜索框；各板块缺少资料时保留安静且明确的空状态，既有医学书默认归入医学。
- 三科第一部分统一为单行书架，最近阅读自动置前，通过左右箭头整组翻页，不使用横向滚动条。医学后两部分为五科名词解释与论述；政治为优题库基础篇与拔高篇；英语为按英语一/二、年份和题型筛选的真题训练，以及独立的翻译与写作。
- 点击书籍进入资料学习主页：保留书名、版本、学科、轻量阅读进度、继续学习入口、真实练习单元与完整分层目录；不再重复展示四项统计和说明性的“三步学习路径”。
- 英语书架直接展示已发布的方法、基础阅读和词汇资料；真题按年份与题型进入结构化客观题答题，翻译和写作保持独立作答入口，不把重复的主观题资料伪装成书目。
- 点击某年英语真题后先进入试卷导读：按原卷顺序列出完形填空、阅读理解各 Text、新题型以及翻译/写作，显示题号范围、题量、共享原文段落数和答题进度；从任一组进入会定位到对应首题，答题页会标明题型与文章编号。
- 英语真题按题型提供不同的做题提示：完形填空保留完整三段原文，并把 1–20 个空显示为可点击的正文空格；点击某空后只在正文下方显示该空选项，选中后沿用原有提交、答案、原书解析和个人解析保存链路。阅读理解提示先读完整文章，Part B 提示为缺口选择合适段落，避免把不同题型压成同一种答题界面。
- 翻译与作文从试卷导览进入独立主观题工作台：左侧保留原题与图文材料，右侧根据题型提供译文 / 作文输入、字符或词数提示、侧边栏个人解析和 Obsidian 保存；完成独立作答后才展开明确配对的参考解析。没有独立解析的年份会清楚标注缺失，不会把整套试卷参考页误当成作文解析。
- 当前已发布 2010–2025 年英语一与英语二客观题包，共 32 个年度题库、每包 45 题；2025 年英语二第 16 空曾因试卷 OCR 的 `read` 与答案/解析的 `recall` 冲突而隔离，已依据同年答案、详细解析及独立公开真题页面恢复为正式题，现为 45 道正式题、0 道隔离题。每题保留原文上下文、独立解析、个人解析和来源映射。原卷翻译、应用文和图画/图表作文不混入选择题库，而是从对应年份导览进入附加阅读资料（英语一第 46–52 题、英语二第 46–48 题）。
- 《考研英语 58 篇基础阅读》已作为独立阅读资料发布（2 章 / 58 个阅读单元 / 5 个 reference 页面），与真题题库分开，不把每篇文章伪装成题目；首篇前的课程前置信息已归档到 reference，不进入正文阅读流。
- 五科政治讲义均已作为独立资料导入书架：马克思主义基本原理（8章/20节）、毛泽东思想和中国特色社会主义理论体系概论（8章/20节）、习近平新时代中国特色社会主义思想概论（17章/55节）、中国近现代史纲要（10章/35节）、思想道德与法治（6章/20节）。它们来自同一份不可变 OCR 归档，但各自保留明确的来源行区间、章节映射和图片资产；“核心考案”只留在 provenance，不成为导航层。包内图片通过受 manifest 约束的本地只读接口访问，不暴露任意文件路径。
- 基础题库与拔高题库已发布到独立的本地 `question-banks/` 运行时目录，保持在书架扫描器之外；`/api/question-banks` 与 `/api/bootstrap` 仅返回真实题量、题型和稳定知识位置，16道基础隔离题不进入正式索引。
- 阅读页只在当前小节存在真实稳定知识位置匹配时显示练习入口；基础题按小节精确关联，未找到小节题才回退到同章，资料主页只显示真实综合测试。
- 完形填空与政治等普通练习仍一次呈现一道真实题，并沿用 YuQuiz 已验证的答题信息层级；英语阅读理解 Text / Part B 则进入整篇阅读工作台：桌面端左侧完整文章、右侧该篇全部题目，可任意选择后提交。作答前不向浏览器返回正确答案或原书解析；提交后才显示答案、原书解析与该题个人解析输入区。
- 普通客观题提供可折叠的题组导航，以题号显示当前、正确、错误和未作答状态；可以随时结束并查看本组已答、正确、待梳理和未作答数量，再返回资料或试卷导览。政治综合练习按题库中的六个真实测试单元呈现，每组30题并独立保存进度，不再把180题伪装成一个无法完成的入口。
- 阅读页、英语整篇阅读和主观题工作台都有明确的完成出口；结束阅读会回到当前资料主页并刷新最近位置、进度和时长，不要求依赖浏览器后退来完成一次学习。
- 个人解析自动保存到本地 `data/practice/`，并按当前题目的稳定学科标签分别重建聚合解析；检测到 Obsidian vault 时写入 `YuReader/<领域>/<学科>/练习解析.md`，否则回退到 `data/practice-notes/`，不会把跨学科题目错误混入题库第一本书，也不会生成一题一个 Markdown 文件。
- 翻译 / 作文的独立作答保存在 `data/subjective/`（状态）与 `data/subjective-notes/`（本机 Markdown 回退），连接 Obsidian 时按年份、题型写入 `YuReader/英语/<科目>/主观题/<试卷>/<题型>·练习.md`；它与选择题判分、原题和参考解析保持独立。
- 医学书架提供独立的“口腔重点”入口：将本地 DOCX 重点资料整理为口外、口组、牙体、牙周、修复五科目录，每次只显示一道名词解释或简答论述题。参考答案在用户主动揭示前不会发送到浏览器；页面提供“理解这道题 / 闭卷口述 / 按点批改”三类 Gemini 侧边栏提示词，并自动保存闭卷作答、漏点记忆和掌握状态。

- 首页采用“继续学习 + 今日有效时长”的双栏主区域，下方固定提供口腔、英语、政治、回顾四个直接入口；口腔入口直达重点背诵，不再要求先进入医学书架寻找。今日轨迹只在存在真实活动时显示，“当前阅读”仍不占用独立导航，阅读页与完整目录统一归入“学习库”。
- 同一日期、活动类型、资源与条目的前台计时和持久产出会在首页、回顾、记录与统计中合并为一条有效活动，时长相加、产出引用合并，原始 `activity.json` 索引不被重写；已完成的回顾保留在今日轨迹与记录中，但不会覆盖阅读或练习的主继续入口。
- “统计”是记录下的统一投入视图，展示今日/累计活动时长、活跃天数、连续学习、近12周热力图，以及医学/政治/英语与阅读、客观题、主观题、笔记、回顾五类活动的真实汇总；这些数据只来自本地活动与产出索引，不推断书籍完成度。
- 顶部主题按钮支持日间/夜间模式切换，偏好保存在浏览器本地（`yureader-theme`）；首次使用时跟随系统主题，手动切换后不再被系统主题变化覆盖。
- 正式目录可作为权威编排来源，形成“书籍 → 章 → 小节”的阅读层级。
- 正式阅读正文统一从第一个“第一章”开始；版权页、前言、目录等前置内容只保留在归档和来源证据中，不进入书架阅读页。
- 当前章节可以直接被浏览器侧边栏 AI 读取和总结。
- 清洗正文与本节笔记分开查看，章节之间可以前后切换。
- 阅读页在不改写来源 Markdown 的前提下隐藏正文中与页面标题重复的首个小节标题，并在正文前生成页内导航；政治小节优先列出“考点”，医学小节列出可可靠匹配的主要结构标题，点击后平滑定位到原文。
- 笔记输入框自动保存到本地 `data/notes/`，不依赖外部 AI API。
- “回顾”入口按真实学习活动聚合跨领域来源，一次性提供统一回顾输入；原始正文、题目、答案、笔记和主观作答仍留在各自文件中。
- 章节笔记继续按稳定小节 ID 原地保存在 `data/notes/`，不会为复习复制正文或生成每日内容快照；检测到 Obsidian vault 时，同时镜像为 `YuReader/<领域>/<学科>/<章节>/<小节>.md`。稳定 ID 写入 YAML frontmatter，不再挤占文件名或增加目录层级。
- 统一回顾结果保存为每日学习记录：本地为 `data/learning-records/YYYY/MM/YYYY-MM-DD.md`，检测到 Obsidian 时镜像为 `YuReader/学习记录/YYYY/MM/YYYY-MM-DD.md`。旧 `data/review-workflow/`、`data/logs/` 和旧每日复习文件继续只读展示，不再接受新写入。
- “记录”入口回看统一每日记录、活动索引与历史旧日志；周视图自动收集选定七天的每日记录，阶段总结可选保存到 `data/learning-records/weekly/YYYY-Www.md` 或 Obsidian 的 `YuReader/学习记录/周报/YYYY-Www.md`，不会重复搬运章节正文。
- 英语周记不再作为学习库功能或入口；既有 `data/english-weekly/`、Obsidian 周记及兼容读取接口保留，不迁移、不删除历史数据。
- Markdown 表格与带 `rowspan` / `colspan` 的受限 HTML 表格可在正文中阅读。
- 导入工作区将原始归档、清洗候选、发布正文、质量报告和未来语义切片分开保存。
- 没有外部 Agent 产物时，可直接用原始 Markdown 与人工复核的 layout 建立可追溯书籍包。
- 直接导入会安全归一化口腔教材中“𬌗”的稳定 OCR 词组，不会全局替换“验”或要求逐条人工审校普通扫描噪声。
- [“𬌗”专业术语对照表](docs/OCCLUSION_TERMS.md)区分完整词组替代、𬌗完全丢失、仅检测候选和必须保留的合法词；导入前可用 `tools/audit_occlusion_terms.py` 只读扫描新书。

## 启动

```powershell
python app.py
```

然后打开 <http://127.0.0.1:8775>。也可以双击 `启动 YuReader.bat`。

桌面快捷方式 `YuReader.lnk` 会调用项目内的轻量原生启动器 `YuReader.exe`（它再复用现有 `启动 YuReader.bat`，不产生第二套启动逻辑）；重建脚本会同时写入桌面和开始菜单的“所有应用”列表。若快捷方式不存在或项目目录发生变化，可运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools/create_desktop_shortcut.ps1
```

随后可在“开始”→“所有应用”→“YuReader”上右键选择“固定到开始屏幕”。

启动器源码位于 `tools/launcher/`；若需重建原生入口，可运行 `dotnet publish tools/launcher/YuReaderLauncher.csproj -c Release -p:PublishAot=true -o tools/launcher/publish`，再将生成的 `YuReader.exe` 放回项目根目录。

把书籍 Markdown 放入 `content/` 后刷新书架即可。内容、章节笔记、统一学习记录和周报默认只保存在本机与用户自己的 Obsidian vault。学习活动仅将日期、稳定资源/条目 ID、活动类型、时长、产出引用和恢复目标写入 `data/activity.json`，不复制书籍正文、题目、答案或笔记内容。旧阅读字段继续保留；无法安全映射到统一条目的历史时长会单独标注，不伪造定位。

口腔 DOCX 重点资料使用确定性本地导入器生成运行时索引，源文件不会被改写，生成的内容和学习进度均由 `.gitignore` 排除：

```powershell
python tools/import_oral_focus.py "C:\Users\Yu\Downloads\口腔"
```

导入规则：YuReader 只展示从原书第一个可靠“第一章”标题开始的章节。书籍信息、版权页、前言和目录等第一章以前的内容不会进入正式书架，但仍保留在 YuBuilder/YuReader 工作区的原始归档和来源映射中；没有可识别第一章的包不会被加载。

已有运行时包可用 `python tools/migrate_first_chapter.py --root content --apply` 做同样的原子边界迁移；迁移报告写入各书包的 `reports/content-boundary.json`，不会改写原始文件或历史发布包。

## 阅读时长与本地接口

阅读、客观题、主观题和回顾工作区处于前台时都会计时；历史英语周记活动仍可被兼容读取和汇总。离开学习页面或浏览器转入后台立即暂停，连续10分钟没有页面活动后暂停，恢复操作后继续。前端约每15秒写入一次增量，因此外部查询最多有一个心跳周期的延迟。单纯打开页面仍会留下可恢复定位，但只有累计至少60秒，或产生真实作答、笔记、主观题或回顾成果时，才计为有效学习活动、活跃日和待回顾来源。活动历史不会按天数自动删除。

其他本机软件可以读取：

```text
GET http://127.0.0.1:8775/api/reading-time
GET http://127.0.0.1:8775/api/reading-time?date=2026-08-24
GET http://127.0.0.1:8775/api/reading-time?days=30
```

响应提供秒数、分钟数、最后写入时间和可选历史数组。服务只监听本机地址；计时记录仍保存在 `data/activity.json`，不包含正文或笔记内容。

## 可追溯 Markdown 导入

真实书籍不要直接复制进正式书架。使用 `tools/import_markdown.py` 先在 `workspace/<book-id>/` 构建，再通过可复核的 layout 将正式目录映射到正文，最后使用 `--publish` 原子发布。导入器既支持已有外部 Agent 候选，也支持直接从原始 Markdown 按复核过的原文行与标题建书；目录映射失败不会污染 `content/`。

《口腔正畸学》第7版和《口腔种植学》第5版的实际导入命令、manifest 字段和目录边界见 [docs/IMPORT.md](docs/IMPORT.md)。

## 设计边界

YuReader 暂不内置模型调用。侧边栏 AI 负责阅读当前页面、总结、问答和可选回顾/阶段总结，YuReader 只负责组织可读上下文、记录统一活动与原子保存。AI 内容不会写入原书正文；统一学习记录、周报、章节笔记、题库作答和主观题作答彼此分开，旧日志与旧回顾工作流只作为历史兼容来源读取。

## UI 继承关系

- `static/styles.css`：直接继承自 YuQuiz 的设计系统基础文件。
- `static/vendor/lucide.min.js` 与 `static/assets/`：复用 YuQuiz 的图标与品牌素材。
- `static/reader.css`：仅保留阅读器专用的少量组合规则，不重写 YuQuiz 的基础组件。
- `static/index.html` 与 `static/app.js`：阅读器自己的最小页面骨架和交互编排。
- `static/markdown.js`：独立、无构建步骤的 Markdown/表格安全渲染模块。
- `yureader/utils.py`：后端运行时共用的纯文本、稳定 ID 与原子写入工具；HTTP 路由仍留在 `app.py`，避免一次性高风险拆分。
- `tools/import_markdown.py` 是旧 Markdown 导入器的唯一实现；根目录 `import_markdown.py` 仅作为兼容入口，避免维护两份相同代码。
